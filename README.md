# 네이버 블로그 글 자동 작성기 (2026년 6월 SEO 적용)

주제 하나만 입력하면 **2026년 6월 최신 네이버 상위노출 규칙**에 맞춘 블로그 글을
자동으로 써주는 프로그램입니다. 결과물은 **밝은 배경 + 상위 1% 블로거 형식(폰트·크기·줄간격)**
으로 꾸며진 HTML 파일과, 사진 자리에 들어갈 임시 이미지로 나옵니다.

> **네이버 가입·로그인 불필요.** 프로그램은 글만 만들어 줍니다.
> 만들어진 글은 내가 직접 네이버 블로그에 붙여넣어 발행합니다.
> (자동 댓글·자동 공감 같은 어뷰징 기능은 들어있지 않습니다. 계정 차단 위험이 있어 제외했습니다.)

---

## 2026년 6월 네이버 SEO, 이 규칙을 반영했어요

검색으로 확인한 최신 규칙입니다. (출처는 맨 아래)

- **진정성 있는 경험이 1순위** — 키워드 반복·글자수 채우기는 오히려 감점
- **C-Rank** — 한 주제에 집중된 전문 블로그가 유리
- **D.I.A.+ / 검색의도 일치** — 검색한 사람의 궁금증을 끝까지 해결
- **AEO 구조** — 질문형 소제목 + 바로 아래 핵심 답변
- **직접 찍은 원본 사진 5장 이상** — 스톡/AI 이미지보다 직접 촬영이 고득점
- **구체적 수치**(가격·시간·날짜)와 1인칭 경험, 솔직한 단점까지

이 규칙들은 [`seo_rules.py`](seo_rules.py) 한 파일에 정리돼 있어요. 규칙이 바뀌면 거기만 고치면 됩니다.

## 방법 A. 화면(웹)으로 쓰기 — 초보자 추천 ⭐

터미널 명령어 없이, 브라우저에서 **주제 적고 버튼만 누르면** 글+사진이 나옵니다.
API 키도 화면에 붙여넣으면 돼서 환경변수 설정이 필요 없어요.

**켜는 법 (한 번만 터미널 사용, 이후엔 전부 클릭):**

```bash
pip install -r requirements.txt   # 처음 한 번만
python web_app.py                 # 화면 켜기 (맥은 python3)
```

- 또는 **더블클릭으로 켜기**: 윈도우는 `start_windows.bat`, 맥은 `start_mac.command` 더블클릭
- 켜지면 브라우저에서 **http://127.0.0.1:5000** 접속
- 주제 입력 → (선택) 경험 메모 → **✨ 글 만들기** 클릭 → 잠시 후 완성된 글이 화면에 뜸
- **전체 글 새 탭에서 열기** → 전체 선택·복사 → 네이버 블로그에 붙여넣기

> 끌 때는 터미널 창에서 Ctrl+C. 다시 쓰려면 `python web_app.py` 만 또 실행하면 됩니다.

## 방법 B. 터미널(명령어)로 쓰기 — 빠르고 자동화에 좋음

```bash
# 1) 필요한 라이브러리 설치
pip install -r requirements.txt

# 2) API 키 등록 (맥/리눅스)
export ANTHROPIC_API_KEY='발급받은_키'
#    윈도우(파워셸)이면:  $env:ANTHROPIC_API_KEY='발급받은_키'

# 3) 글 작성! (주제 + 직접 겪은 경험 메모)
python main.py "성수동 카페 추천" --notes "토요일 오후 방문, 아메리카노 5500원, 웨이팅 20분, 디저트 맛있었음"
```

실행이 끝나면 `output/` 폴더에:

- `제목.html` — 브라우저로 열어보는 완성된 블로그 글
- `images/` — **AI가 생성한 사진** (생성 실패 시 임시 이미지)

## 사진(AI 이미지) 생성

Claude는 글만 쓰고 그림은 못 만들기 때문에, 사진은 외부 서비스로 만듭니다.
두 가지를 자동 지원해요:

| 방식 | 가입/키 | 품질 | 동작 조건 |
|------|---------|------|-----------|
| **Pollinations** (기본) | 불필요(무료) | 준수 | 그냥 실행하면 자동 사용 |
| **OpenAI** (선택) | 필요(유료) | 최고 | `OPENAI_API_KEY` 가 있으면 자동 전환 |

- 아무 설정 없이 실행하면 **무료(Pollinations)** 로 그림이 생깁니다.
  - 무가입 사용 시 작은 워터마크가 있을 수 있고, 가끔 느리거나 실패할 수 있어요(이때 임시 이미지로 대체).
- 더 좋은 품질을 원하면 OpenAI 키를 등록하세요. 자동으로 그쪽을 씁니다.
  ```bash
  export OPENAI_API_KEY='openai_키'   # 있으면 고품질, 없으면 무료로 동작
  ```
- AI 이미지를 끄고 빈 사진 자리만 만들려면 `--no-ai-images` 를 붙이세요.

> 💡 AI 사진은 '초안'입니다. 2026년 네이버는 **직접 찍은 원본 사진**을 더 높게 평가하므로,
> 가능하면 본인 사진으로 교체해 발행하는 게 상위노출에 가장 좋습니다.

## 사용 흐름 (가입 없이 발행까지)

1. `output/제목.html` 을 브라우저로 열어 글 확인
2. 글을 복사해 **네이버 블로그 글쓰기**에 붙여넣기
3. 임시 사진을 **직접 찍은 사진으로 교체** 후 발행
   - 👉 이 단계가 2026년 상위노출의 핵심입니다. 꼭 본인 사진으로 바꾸세요.

## 파일 구성

```
web_app.py     화면(웹) 방식 — 브라우저에서 클릭으로 사용 (방법 A)
main.py        터미널 방식 + 글 생성 핵심 로직 (방법 B)
seo_rules.py   2026 네이버 SEO 규칙 + 상위 1% 글 형식 (여기만 고치면 규칙 업데이트)
render.py      글을 밝은 배경 HTML로 꾸미고 사진 배치
image_gen.py   AI 이미지 생성 (Pollinations 무료 / OpenAI 고품질)
start_windows.bat / start_mac.command   더블클릭으로 화면 켜기
requirements.txt  필요한 라이브러리 목록
```
